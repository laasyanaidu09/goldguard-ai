# GoldGuard: The Intelligent Gold Lifecycle Solution

GoldGuard addresses information fragmentation and wealth tracking by treating physical gold as an active personal asset portfolio.

## Key Solution Pillars

### 1. Invoice & Image Digitization (OWN -> UNDERSTAND)
- Digitizes paper invoices via Gemini Multimodal OCR and Document AI.
- Extracts categories, weight (gross & net), purity, jeweller details, and transaction dates.
- For undocumented pieces, Gemini analyzes photographs to estimate category, style, and typical weight bounds.

### 2. Live Portfolio Valuation (TRACK)
- Tracks each asset's historical buy-in value vs. current market value.
- Provides a detailed breakdown of verified vs. self-reported assets.
- Displays interactive metrics (total net gold weight, purity distributions, and cumulative returns).

### 3. Collection Advisor (DISCOVER)
- Synthesizes the portfolio to identify style and category gaps.
- Recommends 3-5 next purchases to diversify or pair with existing pieces.
- Issues warnings if a target item duplicates current assets.

### 4. Scenario-Based Purchase Planner (PLAN & OPTIMIZE)
- Estimates typical weight ranges and budgets for target designs using Gemini image understanding.
- Models 6/12/18-month timelines.
- Integrates an exchange optimizer that models trading in low-wear items to offset new purchase costs.
- Calculates weekly/monthly savings requirements under 4 market price scenarios (Lower, Current, Moderate, Higher).
